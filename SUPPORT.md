# Support

## How to get help

| Need | Where |
|------|--------|
| Usage / install questions | [GitHub Discussions](https://github.com/hocestnonsatis/Compendium/discussions) (if enabled) or a [question issue](https://github.com/hocestnonsatis/Compendium/issues/new/choose) |
| Bug report | [Bug report template](https://github.com/hocestnonsatis/Compendium/issues/new?template=bug_report.yml) |
| Feature request | [Feature request template](https://github.com/hocestnonsatis/Compendium/issues/new?template=feature_request.yml) |
| Security vulnerability | [SECURITY.md](SECURITY.md) — private reporting only |
| npm package | [`compendium-mcp` on npm](https://www.npmjs.com/package/compendium-mcp) |

## Docs

- [CONTRIBUTING.md](CONTRIBUTING.md) — build, test, PR expectations
